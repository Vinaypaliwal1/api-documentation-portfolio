# API Documentation Portfolio

## Intended Audience

This documentation supports:

* Product managers and business users who need to understand API capabilities
* Developers who integrate applications by using REST APIs

## API Overview

The User Management API enables applications to manage user accounts, including creating profiles, updating user details, and removing inactive users.

## What This Repository Demonstrates

* Clear API explanations for mixed audiences
* Developer-ready request and response examples
* Docs-as-Code workflow that uses GitHub and Markdown
* OpenAPI specification included for machine-readable API contracts
