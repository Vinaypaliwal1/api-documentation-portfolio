\# Glossary



| Term | Meaning |

| --- | --- |

| API | An interface that enables software systems to communicate with each other |

| Endpoint | A specific API operation that performs an action |

| JWT | A secure token used to authenticate and authorize API requests |

| HTTP status code | A standard code that indicates whether a request succeeded or failed |

| Trace ID | A unique identifier used to track a request across systems |
